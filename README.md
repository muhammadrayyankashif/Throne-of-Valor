# Throne of Valor

A browser-based, two-player fantasy fighting game built with JavaScript and Phaser 3. Includes tournament and survival modes, character paths, arena hazards, weapons, and special combat abilities.

**[Play Throne of Valor on itch.io](https://muhammadrayyan.itch.io/throneofvalor)**

## Play

Open `index.html` in a browser with an internet connection. Phaser 3.70 is loaded from jsDelivr.

For a local web server, run `python3 -m http.server 8000` from this folder and open <http://localhost:8000>.

## Controls

- Player 1: WASD to move, Space to attack, double-tap A/D to dash, E for Sacrifice, Q for Blood Gambit.
- Player 2: arrow keys to move, Shift to attack, double-tap left/right to dash, Enter for Sacrifice, Ctrl for Blood Gambit.

The in-game instructions describe combat mechanics and character paths.
